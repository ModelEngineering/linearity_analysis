# Calculating Characteristic Times

The **characteristic time** of a system is the timescale over which the system evolves significantly. This is largely subjective, and depends on what experiments are being conducted.

Currently, characteristic times are calculated by using several algorithms in priority order. That is, if algorithm $n$ is successful, its result is used as the characteristic time. Otherwise, algorithm $n+1$ is used.

## Algorithms

### 1: Endtime specified in SEDML

The SEDML associated with a model in BioModels can specify an ``endtime`` that is used in the study. This is the best option for characteristic time since it reflects the thinking of the user doing the study.

### 2: Steady state analysis

Many models converge to a steady state if simulated for a sufficiently long time. We expect that the "interesting" dynamical activity must have occurred prior to reaching steady state. If steady state can be identified, we backtrack from it to estimate the characteristic time. In current studies, we use 10% of the steady-state time as the characteristic time.

### 3: Maximum of the median coefficient of variation

It may not be possible to find a steady state for some systems. The system may be unstable or there may be numerical issues with calculating steady state.

For these systems, we use a heuristic to identify characteristic times based on the **maximum of the median coefficient of variation (MCV)**. Species concentrations can vary by six to ten orders of magnitude in absolute terms, so we first normalize each species time course by computing its coefficient of variation (standard deviation divided by mean) across the simulation. Intuitively, an endtime is more "interesting" if it captures larger relative fluctuations. For a candidate endtime $t$, we compute the median coefficient of variation across all species over the interval $[0, t]$ — this is the MCV. The endtime that maximizes the MCV is designated as the characteristic time.

## Assessment

The directory `@plots` contains 42 figures generated by `@scripts/plot_biomodels.py`, with 25 models per page. Each figure displays standardized time courses of floating species (z-score normalized: subtract the mean and divide by the standard deviation). For each model, the figure indicates which algorithm produced the characteristic time estimate and the value of that estimate.

## Open Questions and Issues

A review of the generated plots revealed several issues and areas for further investigation:

1. **Overshoot in steady-state and MCV estimates:** Some characteristic times derived from both the steady-state and MCV algorithms appear to grossly overshoot the period of most dynamical activity, suggesting these methods may not always produce biologically meaningful estimates.

2. **Missing plots:** There is no systematic assessment of why certain models lack plots. Possible reasons include: inability to simulate (numerical errors), non-mechanistic model types (e.g., FBA or Qual models), or missing SEDML.

3. **Event handling:** Some models use events, which may distort the dynamical patterns used by the MCV and steady-state algorithms. These models should be assessed for exclusion or handled separately.

4. **Paper-based validation:** For a subset of models, the associated paper should be reviewed to determine whether it explicitly states characteristic times or relevant timescales. AI-assisted literature analysis may be useful here.

5. **Problematic algorithm outputs:** Models 55, 79, 80, and 1030 produced poor MCV or steady-state estimates and warrant closer examination.

6. **Questionable SEDML endtimes:** Some models with SEDML-specified endtimes do not appear to have reasonable values (e.g., models 1027, 1041, 1059). These should be used as reference cases for evaluating the reliability of each algorithm.
