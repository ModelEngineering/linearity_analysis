# Calculating Characteristic Times

The **characteristic time** of a system is the timescale over which the system evolves significantly. This is largely subjective, and depends on what experiments are being conducted.

Currently, characteristic times are calculated by using several algorithms in priority order. That is, if algorithm $n$ is successful, its result is used as the characteristic time. Otherwise, algorithm $n+1$ is used.

## Algorithms

### 1: Endtime specificed in SEDML

The SEDML associated with a model in BioModels can specify an ``endtime`` that is used in the study. This is the best option for characteristic time since it reflects the thinking of the user doing the study.

### 2: Steady state analysis

Many models converge to steady state if the simulation is run for sufficiently long time. So, we expect that the "interesting" activity must have occurred prior to steady state. If we can find steady state, then we can back track to specify the characteristic time. In current studies, we use 10% of the steady state time as the characteristic time.

### 3: Maximum of the median coefficient of variation

It may not be possible to find a steady state for some systems. The system may be unstable or there may be numerical issues with calculating steady state.

For these systems, we use a heuristic to identify characteristic times. We need to do these studies using normalized values because the magnitudes of floating species can vary by six to ten decimal orders of magnitude. Thus, our first step is to calculate the coefficient of variation (standard deviation divided by the mean) for each species time course. Intuitively, an endtime is more interesting if it has larger coefficients of variation. We compare time periods by looking at the median of the coefficient of variation, **MCV**, of the species time courses. The endtime with the largest MCV is designated as the characteristic time.
