# README for Data

* File names with "0.1", "0.01", and "0.001" indicate that the data were produced using SINDy thresholds of 0.1, 0.01, 0.001.
* @data/serialized/timecourse/timecourse.zip contains time courses for BioModels with explicitly specified, non-default end times for 1,000 points. There are no Jacobians.
* @data/linear_predictor_scores-{threshold}.csv are statistics on the accuracy of linear predictions at the threshold.
* @archives are older files that may be needed for historical purposes
